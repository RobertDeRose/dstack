# dStack

dStack makes coding-agent behavior consistent without becoming another workflow
engine. It combines a small deterministic CLI with four targeted skills.

Beads owns the complete feature graph and exposes the next task. Git and
worktrees own repository history and isolation. hk owns repeatable checks.
dStack validates repository policy and supplies compact facts to the skills.

The workflow has five native Beads steps: plan, independent review, human
approval, implementation work, and final drift audit. No Markdown task list or
dStack state file is required to resume work.
